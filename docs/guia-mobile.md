# Fluxo de trabalho no celular
1. Você descreve o vídeo (briefing) no app do Claude Code.
2. O Claude gera/ajusta o storyboard e renderiza **frames-chave + clipe curto** (revisão rápida).
3. Você aprova ou pede ajustes por conversa.
4. Render final nos dois formatos; o MP4 chega pelo chat.
Dica: a nuvem é efêmera — o que não for commitado e enviado ao GitHub se perde.
